# 3CS Homepage

A React + TypeScript frontend project for the 3CS.lk UI/UX homepage assignment. The project is scaffolded with Vite and Oxlint.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm install
npm run dev
```

## Validate and build

```bash
npm run lint
npm run build
```

The production output is generated in `dist/`. Do not use media downloaded from the current 3cs.lk website.
